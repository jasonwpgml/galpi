# Billing 도메인 계획

공식 상태는 `.galpi/source.yaml`에서 관리한다.

Billing은 구현 전 라우팅을 검증하기 위한 계획 전용 도메인이다. 현재 구현 코드와 `src/billing/` 폴더는 없다.

## 목표 범위

- 학생별 청구서 초안 생성
- 수강 신청 내역을 청구 항목으로 변환
- 납부 상태(`draft`, `issued`, `paid`, `void`) 관리
- 통화 금액은 부동소수점 대신 최소 통화 단위 정수로 저장

## 경계

- Billing은 `student`와 `lesson`의 공개 API 또는 향후 정의할 이벤트만 사용한다.
- 결제 수단 저장과 실제 결제사 연동은 이 실험 앱 범위에서 제외한다.
- 구현을 시작하기 전 상태를 WIP로 바꾸고 `src/billing/_map.yaml` 및 status 문서를 만든다.

## 아직 결정하지 않은 사항

- 수강 취소 시 환불/크레딧 정책
- 청구서 번호 생성 규칙
- 세금 및 할인 모델
